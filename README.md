# 📚 StudyFocus

> 🚀 A modern study productivity web application designed to help students plan their daily learning, manage focused study sessions, track their progress, and build better study habits.

## 📖 About The Project  

**StudyFocus** is a student-focused productivity application currently being developed as my **3rd project during my Full-Stack Development Internship at DecodeLabs**.

The main purpose of this project is to create a simple, organized, and user-friendly platform where students can manage their study routine in one place.

StudyFocus combines a **study timer, daily study planning, progress tracking, previous study records, dark mode, Local Storage, and responsive design** to provide an app-like learning experience.

The project is currently **under active development**, and I am continuously working on improving its functionality, UI/UX, responsiveness, and overall user experience.

## ✨ Features

### ⏱️ Study Timer

StudyFocus includes an interactive study timer that helps students maintain focused study sessions.

- ▶️ Start Timer
- ⏸️ Pause Timer
- 🔄 Reset Timer
- ⚡ Quick Timer Options
- 📊 Focus Time Tracking
- 🎉 Session Completion Notification

### 📚 Today's Study Plan

Students can create their daily study plan by entering:

- 📖 Subject
- ⏰ Study Hours
- ⏱️ Study Minutes
- 📝 Topics or Tasks to Study

### 📊 Study Progress

Students can maintain their daily learning progress by recording:

- ✅ What they studied today
- 📝 What they could not complete
- 📅 What they studied yesterday
- 🎯 Daily study goals
- ⏱️ Total focused study time

### 🌙 Dark Mode

A Dark Mode / Light Mode feature is included to provide a comfortable experience in different environments.

### 💾 Local Storage

StudyFocus uses browser **Local Storage** to save important study information so that users can keep their data even after refreshing the page.

### 📱 Responsive Design

The interface is designed to provide a smooth experience across:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile
- 📲 Different screen sizes

## 🛠️ Technologies Used

- 🌐 HTML5
- 🎨 CSS3
- ⚡ JavaScript
- 💾 Local Storage
- 📱 Responsive Web Design
- 🧩 DOM Manipulation
